# Gameplay Booster PRO

Éditeur vidéo gameplay 100 % navigateur (WebGL2 + WebCodecs), hébergé sur Cloudflare.

- Interpolation 30 → 60 fps par estimation de mouvement (shader GPU)
- Netteté, contraste, couleurs, vibrance
- Export MP4 H.264 + AAC, formats TikTok / YouTube / origine
- Avant / après en direct, découpe début/fin

Navigateurs : Chrome / Edge (PC et Android).
